# 抖音网页版弹幕性能优化

一款用于抖音网页版的油猴脚本，保留弹幕观看体验，改善弹幕密集时的播放卡顿、倍速不流畅和进度跳转后弹幕恢复缓慢的问题。

适用于电脑浏览器中的抖音视频页面，不适用于直播间和手机 App。

项目链接：https://github.com/KNaiFen/douyin-danmaku-performance

## 功能

- **弹幕更流畅**：优化密集弹幕的滚动与倍速播放，不通过关闭弹幕或固定数量截断来提速。
- **跳转后恢复画面**：按目标时间恢复正在屏幕上滚动的弹幕，无需全部从边缘重新入场。
- **沿用原站设置**：支持透明度、字号、移动速度、显示区域和弹幕开关。
- **保留表情与标记**：支持抖音 emoji、本人弹幕边框、点赞标记和高赞数量。
- **保留悬停操作**：鼠标移到弹幕上仍可使用原站浮窗和点赞等操作。
- **适配播放操作**：支持暂停、倍速、全屏和播放器尺寸调整。

## 安装方法

1. 在浏览器中安装 [Tampermonkey（油猴）](https://www.tampermonkey.net/) 扩展。
2. 点击 [安装脚本](https://raw.githubusercontent.com/KNaiFen/douyin-danmaku-performance/main/douyin-danmaku-performance.user.js)，在油猴弹出的页面中确认安装。
3. 打开或刷新 [抖音网页版](https://www.douyin.com/)，脚本会自动生效。

无需额外设置，继续使用播放器原有的弹幕设置即可。更新脚本后也需要刷新页面，仅切换视频不会生效。

要恢复原版弹幕，在油猴中禁用此脚本并刷新页面。

- **0.3.1**：优化密集弹幕播放，修复缩放后悬停错位、字号调整后重叠及重复弹幕等问题。
- **0.3.0**：提升弹幕滚动流畅度，完善表情、透明度、点赞标记和悬停交互。
